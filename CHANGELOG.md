## 4.1.0 - 2026-11-26

### Added

- Added a profile-specific minimap button visibility setting and `/rp minimap`
  command to show the button again.
- Added quick-action tooltips with available phrase counts and a class/race
  breakdown.
- Added a No emote option for individual phrases and help for the `%s` target
  name placeholder.

### Changed

- Redesigned the tutorial with scrollable sections and examples, and made it
  reappear for major/minor releases and tutorial feature updates.
- Improved settings window layering, Escape behavior, and emote picker
  appearance and dismissal.
- Positioned the minimap button along the minimap's outer rim.

### Fixed

- Prevented renaming a category to its existing name from reporting a change
  or deleting a custom category.

## 4.0.0 - 2026-11-13

### Added

- Added a first-use tutorial explaining the phrase hierarchy and addon workflow,
  with a Tutorial button in Settings to reopen it.
- Added personality, category, race, and class selectors to phrase management.

### Changed

- Reorganized the manager into Phrases and Settings tabs, moving personality
  and category management into Settings alongside profiles and language.
- Refreshed the main and manager panels with an opaque, Leatrix Plus-inspired
  style and made Personality the first main-panel selector.
- Expanded phrase selection to favor class-specific phrases while retaining
  race-wide phrases for variety and when class phrases are unavailable.
